# Sprint_7
# Yandex Scooter API Tests

## Описание
Набор автотестов для проверки REST API сервиса Яндекс Самокат. Тестируется создание и авторизация курьера, оформление заказа и получение списка заказов.

## Стек технологий
- Python 3.11+
- pytest
- requests
- allure-pytest

##  Структура проекта
```
.
├── api/                   # Обёртки над REST API
├── tests/                 # Тесты API
├── data.py                # Тестовые данные и ожидаемые ответы
├── generators.py          # Генераторы валидных данных
├── urls.py                # Список URL-ов для API
├── conftest.py            # Общие фикстуры
├── requirements.txt       # Зависимости проекта
├── README.md              # Документация
```

### Запуск тестов
```bash
pytest --alluredir=allure-results
```
---

## Что покрыто тестами

### Курьер
- Успешное создание курьера
- Повторное создание с тем же логином
- Отсутствие обязательных полей
- Успешная авторизация
- Ошибки при некорректных данных

### Заказ
- Создание заказа с разными цветами
- Без указания цвета
- Проверка, что `track` приходит в ответе
- Получение списка заказов
